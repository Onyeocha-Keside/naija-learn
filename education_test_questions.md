# Education pilot tasks

Translate tasks naturally into each tested language. Obtain consent for recordings, anonymise participant IDs and record actual phone model, browser, connectivity, language, question and answer. Target devices must be tested directly; desktop simulation alone does not establish compatibility.

## Explanations
1. Explain one half using an orange.
2. How do I add 25 and 17? Explain the steps.
3. What is a verb? Give an example.
4. Why do plants need sunlight?
5. What is the difference between a solid and a liquid?
6. Explain how to wash hands and why it matters.

## Practice and checking
7. Select practice / maths / primary and request a multiplication question. Check that the answer is not revealed immediately.
8. Select check / maths and ask: “What is 7 times 6? I answered 40. Help me understand.”
9. Select check / English and ask: “Find the verb in Amina reads a book. I answered Amina.”
10. Ask to check an answer without giving the question. The tutor should ask for missing information.

## Device and recovery tasks
11. Submit a typed question without JavaScript and read the answer.
12. Deny microphone permission, then type a question.
13. Upload a phone recording; check the recognised question and spoken output.
14. Disable spoken answers and check that no audio is downloaded.
15. Revisit offline after a successful first visit: read starter lessons; live requests should explain that connectivity is needed.
16. Ask with background noise; record transcript usability and failures.
17. Disconnect while submitting; check that the typed question remains available for retry.
18. Ask a follow-up without context. Assess whether the tutor asks for clarification rather than pretending to remember.

## Scoring
Record transcription usability (yes/no), answer correctness reviewed by a teacher, spoken clarity (1–5), learner-rated usefulness (1–5), request success and measured latency. Use actual denominators and distinguish unique participants from interaction counts. Record failures as well as successes.
